## Durability scope and carried-forward gaps

Only server-acknowledged updates are covered by the verified worker-restart guarantee. PostgreSQL may finish an in-flight statement after a client process dies; the before-commit crash test keeps its insert blocked until the database statement timeout aborts, rather than assuming process death proves rollback. The post-commit test kills before broadcast/ACK and later replays the original identity for its original sequence. Snapshot death and renewal death use test-only subprocess IPC barriers; production exposes no fault-injection endpoint.

Phase 05 retains completed local transactions and reconnects automatically; it does not cover local changes before transaction completion, browser eviction/site-data removal/device loss, or loading the web application while all HTTP access is offline. Undo history resets on file close/switch/reload and Phase 06 generation rebind. Rejected generations remain separate drafts; Phase 06 now exercises actual checkpoint restores in addition to historical synthetic replacement tests. A 15-second dead-owner lease and jittered backoff delay admission. Corrupt snapshots require operator repair. Payload quota excludes snapshot/table/index overhead; retained logs require storage monitoring/backups.
